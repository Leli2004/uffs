
## Exercício 1
### Nível: Fixação / Compreensão

Domínio: 
* Estação de Monitoramento Agroecológico do Alto Uruguai

Descrição:
* Uma cooperativa de monitoramento ambiental em Chapecó-SC necessita de um
componente de software para representar sensores climáticos distribuídos em lavouras
sustentáveis.

## Exercício 2
### Nível: Aplicação / Análise

Domínio: 
* Sistema de Conta de Crédito Comunitário

Descrição:
* Projete a camada de domínio para uma cooperativa de crédito regional. A classe não deve
permitir acesso público direto ao saldo financeiro, utilizando métodos orientados ao domínio
que reportam o sucesso ou fracasso das transações.

## Exercício 3
### Nível: Síntese / Projeto Integrador

Domínio: 
* Rastreabilidade e Certificação de Lotes de Sementes

Descrição:
* Implemente um modelo de controle para lotes de sementes agroecológicas onde as
transições de estado de certificação determinam quais operações podem ser realizadas.
